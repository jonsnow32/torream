# Chromecast

ZippyPlayer includes built-in Chromecast support, allowing you to stream your videos to any Chromecast-enabled device with just a tap.

## Overview

Chromecast features include:
- One-tap casting
- Remote playback control
- Queue management
- Subtitle support
- Audio track selection
- Background casting
- Multiple device support

## Getting Started

### Prerequisites

**Requirements**:
- Chromecast device or Chromecast built-in TV
- Same WiFi network for phone and Chromecast
- ZippyPlayer installed on Android device

**Supported Devices**:
- Chromecast (all generations)
- Chromecast Ultra
- Chromecast with Google TV
- TVs with built-in Chromecast
- Android TV devices

### Initial Setup

1. **Connect Chromecast**:
   - Plug into TV HDMI port
   - Connect to WiFi network
   - Complete setup via Google Home app

2. **Connect Phone**:
   - Ensure phone on same WiFi
   - Open ZippyPlayer
   - Cast icon appears automatically

## Casting Videos

### Starting a Cast

1. Open video in ZippyPlayer
2. Tap Cast button (‣ icon)
3. Select your Chromecast device
4. Video begins playing on TV
5. Control from phone

### Cast Button Location

**In Player**:
- Top-right corner
- Always visible during playback
- Pulsing icon when casting

**In Library**:
- Long-press video
- Select "Cast"
- Choose device

### Casting Options

**Before Casting**:
- Select quality
- Choose audio track
- Enable subtitles
- Adjust settings

**During Casting**:
- Change subtitles on-the-fly
- Switch audio tracks
- Adjust playback speed
- Control volume

## Playback Control

### Phone Controls

**Basic Controls**:
- Play/Pause
- Seek forward/backward
- Volume control
- Stop casting

**Advanced Controls**:
- Playback speed (if supported)
- Subtitle selection
- Audio track selection
- Next/Previous (in queue)

### Lock Screen Controls

**When Phone Locked**:
- Playback controls visible
- Play/Pause button
- Seek buttons
- Stop casting option

### Notification Controls

**Casting Notification**:
- Always visible when casting
- Play/Pause
- Stop casting
- App name and video title

## Queue Management

### Creating a Queue

**Add to Queue**:
1. While casting
2. Browse library
3. Long-press video
4. Select "Add to Cast Queue"

**Queue from Playlist**:
1. Open playlist
2. Tap "Cast Playlist"
3. Entire playlist added

### Managing Queue

**View Queue**:
- Tap queue icon in player
- See all queued videos
- Current playing highlighted

**Reorder Queue**:
- Long-press and drag
- Move videos up/down
- Changes take effect immediately

**Remove from Queue**:
- Swipe left on video
- Or tap remove button
- Current video can't be removed

### Auto-Play Next

**Automatic Playback**:
- Plays next video when current ends
- Can be disabled in settings
- Works with playlists

## Subtitle Support

### Casting with Subtitles

**Supported Formats**:
- WebVTT (.vtt)
- SubRip (.srt)
- TTML

**How to Enable**:
1. Before casting: Select subtitles
2. During casting: Change via phone controls
3. Subtitles rendered on TV

**Subtitle Styling**:
- Uses TV's subtitle preferences
- Or ZippyPlayer's settings
- Size, color, position

### Troubleshooting Subtitles

**Subtitles Not Showing**:
- Check format compatibility
- Verify subtitle file encoding
- Try different subtitle track
- Restart cast session

**Supported Audio**:

## Troubleshooting

### Cannot Find Chromecast

**Solutions**:
1. Verify same WiFi network
2. Restart Chromecast
3. Restart phone WiFi
4. Check firewall settings
5. Update Google Play Services

### Casting Disconnects

**Causes**:
- Network instability
- WiFi interference
- Router issues

**Solutions**:
- Move closer to router
- Reduce WiFi interference
- Restart router
- Use 5GHz WiFi if available

### Video Buffering on TV

**Causes**:
- Slow network
- High quality selected
- Network congestion

**Solutions**:
- Lower video quality
- Close other network apps
- Check Chromecast connection
- Use wired connection for Chromecast

### Audio/Video Out of Sync

**Solutions**:
- Stop and restart cast
- Try different audio track
- Check source file
- Update Chromecast firmware

### Subtitles Not Syncing

**Solutions**:
- Adjust subtitle delay in app
- Restart cast session
- Try different subtitle format
- Reload subtitle file

## Tips & Best Practices

### For Best Experience

1. **Use 5GHz WiFi**: Faster, less congestion
2. **Wired Ethernet**: For Chromecast Ultra
3. **Close Background Apps**: Free up bandwidth
4. **Good Router Placement**: Strong signal
5. **Update Firmware**: Latest Chromecast version

### Battery Saving

1. **Lower Screen Brightness**: While casting
2. **Enable Battery Saver**: In ZippyPlayer settings
3. **Lock Screen**: When not controlling
4. **Use WiFi**: More efficient than cellular

### Quality Tips

1. **Match TV Resolution**: Don't exceed TV capability
2. **Auto Quality**: For variable networks
3. **4K Content**: Requires Chromecast Ultra
4. **HDR**: Check Chromecast and TV support

## Limitations

### Known Limitations

**Format Support**:
- Some codecs may not cast (rare)
- DRM-protected content may not work
- Very high bitrate videos may buffer

**Network**:
- Requires WiFi (guest mode exception)
- Minimum 5 Mbps recommended
- 25+ Mbps for 4K

**Features**:
- Playback speed may not be supported
- Some gestures not available
- Picture-in-Picture not applicable

## Privacy & Security

### Data Handling

**What's Shared**:
- Video metadata (title, duration)
- Playback position
- Subtitle preferences
- Audio selection

**What's Not Shared**:
- Personal information
- Browsing history
- Private data

**Network Security**:
- Local network only
- No cloud upload
- Direct device-to-device
