# Features Overview

Torream is packed with powerful features that make it a comprehensive media solution for Android devices. This document provides an overview of all major features.

## Core Features

### 🎥 Advanced Video Player

- **Multi-format support**: MP4, MKV, AVI, WebM, and more
- **Codec support**: H.264, H.265, VP9, AV1
- **Adaptive streaming**: HLS and DASH protocols
- **Custom controls**: Intuitive gesture-based interface
- **Picture-in-Picture**: Watch while using other apps
- **Subtitle support**: SRT, ASS, VTT with customization
- **Multiple audio tracks**: Switch between audio languages
- **Playback speed control**: 0.25x to 2x speed

[Learn more about the Video Player →](./video-player.md)

### 📥 Download Manager

- **Multi-protocol downloads**: HTTP, HLS, and Torrents
- **Resume support**: Pick up interrupted downloads
- **Background downloading**: Download while using other apps
- **Queue management**: Control download order and priority
- **Parallel downloads**: Multiple downloads simultaneously
- **Speed limiting**: Control bandwidth usage
- **Auto-retry**: Automatic retry on failure
- **Network awareness**: Pause on connection loss

[Learn more about Download Manager →](./download-manager.md)

### 🌊 Torrent Support

- **Full torrent client**: Download via torrent files and magnet links
- **Sequential downloading**: Prioritize playback-friendly downloads
- **Streaming support**: Watch while downloading
- **DHT and PEX**: Distributed peer discovery
- **Speed controls**: Upload/download limits
- **LibTorrent4j powered**: Robust torrent implementation

[Learn more about Torrent Support →](./torrent-support.md)

### 📚 Media Library

- **Organized storage**: Automatically catalog your media
- **Smart playlists**: Create and manage custom playlists
- **Favorites**: Quick access to frequently watched content
- **Search functionality**: Find content quickly
- **Sort and filter**: Multiple organization options
- **Thumbnail generation**: Visual preview of videos
- **Metadata management**: Track duration, size, date added
- **Storage statistics**: Monitor space usage

[Learn more about Media Library →](./media-library.md)

### 📺 Android TV Support

- **Leanback UI**: Optimized for large screens
- **D-pad navigation**: Full remote control support
- **Voice search**: Google Assistant integration
- **Recommendations**: Home screen content suggestions
- **10-foot UI**: Designed for couch viewing
- **Smooth navigation**: Fast and responsive interface

[Learn more about Android TV →](./android-tv.md)

### 📡 Chromecast Integration

- **Cast to TV**: Stream to any Chromecast device
- **Remote control**: Control playback from phone
- **Queue management**: Manage cast queue
- **Media3 Cast**: Built on Google's Cast framework
- **Background casting**: Continue casting while browsing

[Learn more about Chromecast →](./chromecast.md)
