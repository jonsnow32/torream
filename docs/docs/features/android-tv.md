## Remote Control

### Standard Controls

**Directional Pad (D-pad)**:
- Up/Down/Left/Right: Navigate menu items
- Center/OK: Select item
- Back: Go back one level
- Home: Return to Android TV home

**Playback Controls**:
- Play/Pause: Toggle playback
- Fast Forward: Skip forward
- Rewind: Skip backward
- Stop: Stop playback

### Advanced Controls

**Number Keys** (if available):
- 0-9: Jump to percentage (1=10%, 5=50%, etc.)

**Menu Button**:
- Access additional options
- Subtitle settings
- Audio tracks
- Video quality

## Tips for TV Use

### Best Practices

1. **Use Wired Connection**: For 4K and large downloads
2. **Adjust Subtitle Size**: Larger for TV viewing distance
3. **Enable Voice Search**: Faster than typing
4. **Use Favorites**: Quick access to frequent content
5. **Configure Auto-Play**: Seamless binge-watching

### Optimize Performance

1. **Clear Cache Regularly**: Keep app running smoothly
2. **Close Unused Apps**: Free up memory
3. **Restart Periodically**: Refresh system
4. **Update App**: Latest optimizations

## Troubleshooting

### Remote Not Working

**Solutions**:
- Check batteries
- Re-pair remote
- Try alternative input method
- Restart TV

### Navigation Lag

**Solutions**:
- Clear app cache
- Restart app
- Free up TV storage
- Check TV performance

### Video Won't Play

**Solutions**:
- Check network connection
- Verify file format
- Try lower quality
- Clear app data

### Audio Out of Sync

**Solutions**:
- Use audio delay adjustment
- Change audio track
- Check TV audio settings
- Restart playback
