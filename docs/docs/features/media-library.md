# Media Library

The Media Library is your central hub for organizing and accessing all your video content in ZippyPlayer. It provides powerful tools for managing, searching, and organizing your media collection.

## Overview

Library features include:
- Automatic media cataloging
- Playlist management
- Favorites system
- Smart search
- Multiple sort options
- Storage statistics
- Thumbnail generation
- Metadata tracking

## Library Organization

### Main Sections

**All Media**:
- Complete video collection
- Downloaded files
- Locally scanned videos
- Recently added

**Playlists**:
- Custom playlists
- System playlists
- Shared playlists

**Favorites**:
- Starred videos
- Quick access
- Frequently watched

**Recent**:
- Recently added
- Recently watched
- Continue watching

### View Modes

**Grid View**:
- Thumbnail grid
- 2-4 columns (adjustable)
- Large previews
- Compact information

**List View**:
- Detailed list
- More metadata visible
- Smaller thumbnails
- Better for sorting

## Media Information

### Displayed Metadata

For each video:
- **Thumbnail**: Auto-generated preview
- **Title**: File name or custom title
- **Duration**: Video length
- **Size**: File size
- **Resolution**: Video quality (e.g., 1080p)
- **Date Added**: When downloaded/added
- **Progress**: Watch progress indicator

### Detailed View

Tap any video to see:
- Full metadata
- File path
- Format information
- Codec details
- Bitrate
- Frame rate
- Audio channels

## Playlist Management

### Creating Playlists

1. Tap "+ New Playlist"
2. Enter playlist name
3. Optionally add description
4. Tap "Create"

### Adding to Playlists

**Method 1: From Video**
1. Long-press video
2. Select "Add to Playlist"
3. Choose playlist(s)

**Method 2: From Playlist**
1. Open playlist
2. Tap "Add Videos"
3. Select videos
4. Tap "Add"

### Managing Playlists

**Rename**:
- Long-press playlist
- Select "Rename"
- Enter new name

**Reorder**:
- Open playlist
- Long-press and drag videos
- Automatic save

**Delete**:
- Long-press playlist
- Select "Delete"
- Confirm (videos not deleted)

### Smart Playlists

**Auto-Generated**:
- Recently Added
- Most Watched
- Unwatched
- Favorites

**Rules**:
- Cannot be deleted
- Auto-updated
- Filterable

## Favorites System

### Adding Favorites

**From Library**:
- Long-press video
- Tap star icon

**During Playback**:
- Tap star button
- Instantly added

**Bulk Add**:
- Select multiple videos
- Tap "Add to Favorites"

### Managing Favorites

**View All**:
- Library > Favorites tab
- Sorted by date added

**Remove**:
- Tap star again to unstar
- Or remove from favorites list

## Media Actions

### Single Video Actions

Long-press any video:
- **Play**: Start playback
- **Add to Playlist**: Add to one or more playlists
- **Favorite**: Toggle favorite status
- **Share**: Share via Android share sheet
- **Delete**: Remove from library and storage
- **Rename**: Change display name
- **Details**: View full information
- **File Location**: Open in file manager

### Bulk Actions

Select multiple videos:
- **Play All**: Add to queue
- **Add to Playlist**: Bulk add
- **Favorite**: Bulk favorite
- **Delete**: Bulk delete
- **Share**: Share multiple
- **Move**: Change location

## Thumbnails

### Automatic Generation

**How It Works**:
- Extracts frame from video
- Typically at 10% position
- Cached for fast loading
- Generated in background

**Regenerate**:
- If thumbnail failed
- Tap video > Details > Regenerate

### Custom Thumbnails

**Set Custom**:
1. Open video details
2. Tap thumbnail
3. Choose image
4. Crop/adjust
5. Save

## Troubleshooting

### Videos Not Showing

**Solutions**:
- Rescan folders
- Check file formats
- Verify permissions
- Clear app cache

### Thumbnails Not Loading

**Solutions**:
- Regenerate thumbnails
- Clear thumbnail cache
- Check storage space
- Wait for background generation

### Slow Library Loading

**Solutions**:
- Reduce library size
- Clear cache
- Lower thumbnail quality
- Optimize database
